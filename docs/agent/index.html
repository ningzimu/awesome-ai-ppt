让 AI 学会使用和贡献这个清单

告诉 AI 你的场景、材料和偏好，它会用 awesome-ai-ppt skill 帮你个性化推荐最合适的 AI PPT 工具；也可以在你需要时辅助提交问题、准备 PR，一起贡献这个项目。

安装 Skill 查看示例

一句话让 AI 安装

把下面这句话发给你的 AI agent：

帮我安装 awesome-ai-ppt skill：https://github.com/ningzimu/awesome-ai-ppt/tree/main/skills/awesome-ai-ppt

手动安装

npx -y skills@latest add ningzimu/awesome-ai-ppt \
  --skill awesome-ai-ppt \
  --agent codex \
  --global

用于工具选型

直接告诉 AI 你要做什么、有哪些输入材料、是否需要可编辑、是否要本地运行或接入 agent，它会结合你的真实需求推荐合适项目。 

我想把一篇技术文章做成可编辑 PPT，重视后续修改和自动化，请使用 awesome-ai-ppt skill 帮我推荐最合适的 AI PPT 项目。

用于贡献清单

只有当你明确要求反馈问题、修改清单、提交 Issue 或准备 PR 时，skill 才会进入贡献流程。 

请使用 awesome-ai-ppt skill，检查这个 GitHub 项目是否适合加入清单。
