一句话让 AI 安装

把下面这句话发给你的 AI agent：

帮我安装 awesome-ai-ppt skill：https://github.com/ningzimu/awesome-ai-ppt/tree/main/skills/awesome-ai-ppt

手动安装

npx -y skills@latest add ningzimu/awesome-ai-ppt \
  --skill awesome-ai-ppt \
  --agent codex \
  --global

用于工具选型

本清单适合发现候选项目，但详细判断必须回到原始仓库。让 AI 对比时，要求它阅读 README、文档、示例、安装方式和维护情况。 

请使用 awesome-ai-ppt skill，先用清单粗筛，再去原仓库详细对比适合生成可编辑 PPTX 的方案。

用于贡献清单

只有当你明确要求反馈问题、修改清单、提交 Issue 或准备 PR 时，skill 才会进入贡献流程。 

请使用 awesome-ai-ppt skill，检查这个 GitHub 项目是否适合加入清单。
