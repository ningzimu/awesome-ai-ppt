# Contributing

Thanks for helping improve Awesome AI PPT.

## Add a Project

Please add projects that are directly related to AI presentation generation, PowerPoint automation, PPTX editing, slide conversion, or agentic presentation workflows.

Each entry should use this format:

```md
- [owner/repo](https://github.com/owner/repo) - Short factual description.
```

## Inclusion Guidelines

Good candidates:

- Are open source or source-available on GitHub.
- Generate, edit, inspect, convert, or evaluate presentations.
- Have clear setup or usage instructions.
- Make the output format clear, such as PPTX, PDF, HTML slides, images, or video.

Avoid:

- Closed SaaS products with no useful repository.
- Generic LLM wrappers with no presentation-specific workflow.
- Dead links, empty repos, or projects with no README.
- Marketing copy in descriptions.

## Categories

Use the closest existing category. If a project fits multiple categories, place it where a reader would most likely look first.
